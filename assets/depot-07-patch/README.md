# Нашивка «Депо 07»

`depot-07.glb` объединяет меш и текстуру 256 × 256. Исходники для редактирования находятся в `depot-07.obj`, `depot-07.mtl` и `depot-07.png`. Меш содержит 44 треугольника и имеет замкнутую геометрию с нормалями наружу.

Roblox Studio импортировала GLB в отдельное локальное место. Размер MeshPart составил 0,62 × 0,52 × 0,065 студов, текстура загрузилась. На трёх тестовых манекенах R15 с пропорциями Classic, Normal и Slender вручную проверено соединение `RightShoulderAttachment` с `RightUpperArm`. Автоматическое соединение через `Humanoid:AddAccessory` в редакторе не появилось, поэтому проверка использовала ручной Weld. Анимации, автоматическая примерка и проверка Marketplace ещё предстоят.

Для оформления каталогового аксессуара импортировать GLB, выбрать Shoulder в [Accessory Fitting Tool](https://create.roblox.com/docs/avatar/accessory-fitting-tool), настроить `RightShoulderAttachment` и проверить анимации. В каталог нашивка пока не загружена.
