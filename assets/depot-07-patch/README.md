# Нашивка «Депо 07»

Исходник жёсткого аксессуара: `depot-07.obj`, `depot-07.mtl`, `depot-07.png`. Модель — 24 вершины, 44 треугольника после триангуляции; карта цвета 256 × 256.

Для подготовки к каталогу импортировать модель с текстурой, примерить в Studio через [Accessory Fitting Tool](https://create.roblox.com/docs/avatar/accessory-fitting-tool) как Shoulder, справа на `RightShoulderAttachment`. Проверить Normal, Slender и Classic, включая анимации. Если импортёр требует FBX/glTF, открыть OBJ с MTL в Blender и экспортировать одним мешем. Эта модель ещё не проходила примерку, проверку каталога или модерацию. Публикация выполняется после проверки спроса и условий аккаунта, без расходования Robux в рамках этой работы.
