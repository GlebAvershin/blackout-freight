# Нашивка «Депо 07»

`depot-07.glb` объединяет меш и текстуру 256 × 256. Исходники для редактирования находятся в `depot-07.obj`, `depot-07.mtl` и `depot-07.png`. Меш содержит 44 треугольника и имеет замкнутую геометрию с нормалями наружу.

Roblox Studio импортировала GLB в отдельное локальное место. Размер MeshPart составил 0,62 × 0,52 × 0,065 студов, текстура загрузилась. На трёх тестовых манекенах R15 с пропорциями Classic, Normal и Slender вручную проверено соединение `RightShoulderAttachment` с `RightUpperArm`. Автоматическое соединение через `Humanoid:AddAccessory` в редакторе не появилось, поэтому проверка использовала ручной Weld. В симуляции Studio на каждом манекене проверены повороты плеча на −65°, 40° и 95°. Рука двигалась, расстояние между точками крепления во всех девяти положениях оставалось меньше 0,01 студа.

В [Accessory Fitting Tool](https://create.roblox.com/docs/avatar/accessory-fitting-tool) проверена статическая посадка с настройками `Shoulder → Right Shoulder → Classic Blocky`. Для созданного аксессуара явно задан `AccessoryType = Shoulder`. [UGC Validation](https://create.roblox.com/docs/marketplace/validation-system) в категории `ShoulderAccessory` показал два предупреждения о детализации и разрешении текстуры. Ошибок в отчёте не было.

`depot-07-shoulder.rbxm` сохранён из Studio и повторно импортирован через `File → Import Roblox Model` в ту же локальную сцену. Тип, размер `Handle`, его ссылки на меш и текстуру и положение `RightShoulderAttachment` совпали с оригиналом. Studio успешно загрузила оба ресурса. RBXM ссылается на ресурсы Roblox, поэтому доступность под другим аккаунтом не проверена. Для самостоятельного повторного импорта геометрии и текстуры используйте `depot-07.glb`.

На повторно импортированной копии в симуляции Studio проверены стандартные анимации R15 `Walk`, `Run` и `Wave` на манекене Classic. Рука двигалась во всех трёх анимациях. В 20 замерах на клип расстояние между точками крепления оставалось нулевым в пределах точности измерения, а отклонение угла было меньше 0,001 радиана. Для симуляции использован временный ручной Weld: вызов `Humanoid:AddAccessory` на тестовом манекене не создал `AccessoryWeld`. Проверка охватывает удержание на плече при движении. Публикация и модерация Marketplace ещё не проводились.
