# Тревога 5: профиль дронов в Studio

Одна машина Apple M4, Roblox Studio 0.747, локальный сервер и четыре отдельных клиента. Западный обход, одинаковое начальное состояние, 5 секунд прогрева, затем по 10 секунд патруля и погони. В погоне один игрок подбирает батарею через штатный серверный обработчик; тест перемещает его по открытому коридору выше радиуса захвата. Прогон засчитывается только при четырёх игроках на обоих этапах и непрерывной погоне во втором окне. Тестовые изменения живут во временном месте Studio.

```sh
python3 scripts/run-drone-profile.py --ref 3754656 --rojo .tools/rojo/rojo
python3 scripts/run-drone-profile.py --rojo .tools/rojo/rojo
```

Замер включает серверную функцию `moveDrone`, в том числе укрытия и щит, и отдельно выделяет перемещения деталей. `total_ms` и `transforms_ms` указаны в формате среднее / медиана / p95. `parts` — число деталей, которым игровой код напрямую задаёт положение; это не счётчик сетевых пакетов. `tick_gap_ms` — интервал планировщика, а не время выполнения логики. FPS, сетевой трафик и нагрузка графики на телефоне не измерялись.

На исходной сборке перемещения заняли 77% среднего времени обновления на патруле (0,0707 из 0,0922 мс) и 52% в погоне (0,0549 из 0,1063 мс). Сервер двигал три модели по восемь независимо закреплённых деталей. Теперь у каждой модели одна закреплённая основа, к которой жёстко присоединены декоративные детали. Сервер двигает только основу. Маршруты, скорости, проверки видимости и условия захвата остались прежними. См. [описание сборок деталей Roblox](https://create.roblox.com/docs/physics/assemblies).

Обе сборки держали около 16 обновлений/с. Прямых изменений положения стало до восьми раз меньше. По времени результаты пересекаются: оба новых прогона быстрее второго исходного по среднему времени, но медленнее первого исходного. Прежняя просадка до 10–11 Гц означала интервалы около 90–100 мс между обновлениями. Измеренные тогда 1–4 мс на функцию сами по себе не объясняют разницу с интервалом около 62 мс в контрольных запусках. Просадка не воспроизвелась; её точная причина и устойчивый выигрыш по полному серверному времени не подтверждены. Запуск с тремя подключившимися клиентами исключён. В обоих новых прогонах проверены положение деталей относительно корпуса, отсутствие коллизий и работа луча при погоне.
