## Компас первой смены · инженерная реализация

* **Игровая инженерия:** Новый игрок может потерять шлюз из виду при переноске первой батареи в темноте. Компас проецирует направление цели на границу экрана и автоматически выключается после первой доставки. Сервер распределяет варианты эксперимента и фиксирует действия; клиент рассчитывает направление относительно камеры с 8px гистерезисом.
* **Аналитический инструментарий:** Скрипты на Python и MCP-агенты проверяют целостность эксперимента, считают статистический аплифт и проводят проверку SRM ($\chi^2$).
* **Платформенная отказоустойчивость:** Сервер MCP предоставляет контракт по stdio. Две реплики Kubernetes с базой PostgreSQL протестированы на устойчивость к rolling restart с сохранением сессионных данных. [Код сервера](../analysis/freight_mcp.py) · [CI](../.github/workflows/verify.yml)

## 5-минутный тестовый сценарий

1. Откройте сборку в Roblox Studio и нажмите **Play**. Отверните камеру от первой батареи, чтобы увидеть стрелку HUD-компаса.
2. Подойдите к батарее, нажмите **E** для захвата и следуйте за янтарным маркером шлюза.
3. Вставьте батарею в приёмник: компас выключится, а на табло загорится первый индикатор питания.
