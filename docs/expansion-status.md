- [x] Параметры Sentinel вынесены в Config.Drone, заготовлены Heat 1–3. В игре действует Heat 1 с прежними скоростями.
- [x] Владение пропусками и обработка завершения покупки вынесены в CommerceService.

- [x] CLI-тесты профиля: конфликт серверов, повтор callback, потерянный ответ, повторная покупка, недостаточный баланс, истечение аренды, неизвестная версия данных.
- [x] CLI-тесты перемещений: нормальная скорость, устойчивое ускорение, телепорт, восстановление, нечисловые координаты.

- [x] Studio: профиль, начальный ранг, старт смены и проверка неподвижного игрока — PASS.
- [x] Studio mobile на этапе разделения сервисов: short landscape 638×241 и portrait 413×756 — PASS.
